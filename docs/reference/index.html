Layout on disk

atom writes to two directories inside your project, both safe to delete and both worth adding to .gitignore:

your-project/
├── atom.toml
├── build/
│   ├── .cache/            content-addressed build cache
│   ├── linux-arm64/       isolated copy of your tree, per target
│   └── macos-arm64/
└── dist/
    ├── linux-arm64/       the raw binary for that target
    ├── macos-arm64/
    ├── name-1.0-linux-arm64.tar.gz
    └── SHA256SUMS

build/
dist/
