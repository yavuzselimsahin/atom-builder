Install

atom is a single C program with no dependencies beyond libc. Building it takes a few seconds.

git clone https://github.com/yavuzselimsahin/atom-builder.git
cd atom-builder
make
make install PREFIX=~/.local

~/.local/bin is already on PATH on most systems and needs no sudo. Leave PREFIX out to install into /usr/local/bin instead, which does.

Check it worked:

atom version

What else you need

atom drives other programs rather than reimplementing them. Which ones you need depends on what you ask it to do.

ToolNeeded forWhen
cc, makeBuilding atom itselfAlways
zigCross-compilersAny target using the default zig strategy
Your own toolchainCompiling your projectcargo, go, dotnet — whatever your project uses
gzipCompressionatom package
rsync, sshUploading to a serveratom publish with an ssh destination
curlGitHub Releases APIatom publish with a GitHub destination
dockerEmulationContainer builds, and verifying Linux binaries from a non-Linux host
wineRunning Windows binariesVerifying Windows targets

Only the first two are needed to build anything at all. The rest are checked when a command actually needs them, and atom says which one is missing rather than failing obscurely.

Installing zig

zig supplies the cross-compilers that make one machine able to build for all the others. Any recent version works.

brew install zig          # macOS

Or download a build from ziglang.org/download and put it on your PATH. atom only ever calls zig cc and zig version.

Where atom runs

atom uses fork, execvp and poll, so it runs on macOS, Linux and the BSDs.

Windows is a first-class target — atom builds Windows binaries happily from any of those hosts — but atom does not yet run on Windows.

Working on atom itself

If you are changing atom's own source, make link symlinks the binary instead of copying it, so a rebuild takes effect immediately:

make link PREFIX=~/.local

make clean then leaves a dangling link until you rebuild, which shows up as command not found. Use make install for a copy that survives.

make uninstall PREFIX=~/.local removes either kind.
